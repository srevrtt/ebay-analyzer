eBay Analyzer

How do you use it?

  1. Go to eBay and search for the item you want to see pricing data for.
  2. Select everything with CTRL-A (Windows) or CMD-A (macOS). Copy the selection.
  3. Paste the selection into the box below.
  4. Click the "Analyze" button below and read the results.
